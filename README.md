# c-programming-practice
A collection of beginner-friendly C programs I'm writing while learning and practicing c

# Product Stock Checker

I made this program to practise taking product details from the user. It asks for the product ID, quantity, and price, calculates the total value, and tells you if the stock is low when the quantity is less than 10.

# What I used

- Variables and data types
- "printf()" and "scanf()"
- Basic calculations
- "if-else" statements
